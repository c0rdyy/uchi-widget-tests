# Тестовое задание

## Исправленные ошибки

**Тесты (widget.spec.ts)**
1. В `beforeEach` `page.click('._UCHI_COOKIE__button')` падал по таймауту, если попапа с куки нет, теперь тест ждёт попап через `waitFor` и кликает, только если он появился.
2. `page.goto('/')` ждал загрузки всех ресурсов, было заменено на `waitUntil: 'domcontentloaded'`, чтобы тест не зависел от медленных и необязательных ресурсов.
3. Проверка заголовка `expect(await getTitle()).toEqual(...)` читала текст один раз и могла получить старый заголовок. Было заменено на `await expect(getTitle()).toHaveText(...)`, чтобы проверка заголовка ждала, пока экран реально переключится, а не читала текст в первый попавшийся момент.
4. Перед `articles[0].click()` добавлена проверка, что список статей не пуст.
5. Был убран неиспользуемый параметр `{ page }`, тесты переименованы в формат `should ...`.

**Page Object (widget.page.ts)**
1. В `BUTTON_WRITE_TO_US` `[class^=btn]` был заменён на `.[data-test=button_feedback_form]`, так как старый селектор был слишком общий.
2. В `getPopularArticles()` добавлено ожидание списка, так как `.all()` не ждёт и мог вернуть пустой массив.
3. `getTitle()` теперь возвращает `Locator` вместо строки.
4. Во всех методах-действиях добавлен `await`.

## Добавлено
- Тест `should close widget after opening`, `BUTTON_CLOSE` и метод `closeWidget` для проверки возможности закрытия виджета после открытия
